## Tips for Success

1. **Understand, Don't Memorize**: For each problem, understand WHY the solution works.

2. **Time Complexity Analysis**: After solving, analyze time and space complexity.

3. **Pattern Recognition**: Similar problems use similar patterns:
   - Two pointers for sorted arrays
   - Sliding window for continuous subarrays
   - Hash maps for quick lookups
   - Sorting + greedy for optimization

4. **Practice Order**: 
   - Easy → Medium (same topic) → Hard
   - Don't jump to hard immediately

5. **Common Techniques Across Problems**:
   - **Hash Map**: Fast lookups
   - **Two Pointers**: Optimization
   - **Sorting**: Simplify problem
   - **Prefix Sum**: Range queries
   - **Greedy**: Optimal choice at each step
   - **Binary Search**: Divide and conquer
